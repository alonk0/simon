# משחק סיימון (Simon)

משחק הזיכרון Simon למובייל, בעברית: צפו ברצף הצבעים וחזרו עליו, עד 10 שלבים. האתר עובד גם ללא אינטרנט ואפשר להתקין אותו על הטלפון.

**כתובת:** https://alonk0.github.io/simon/

## התקנה על הטלפון

- **Android (Chrome):** פתחו את הכתובת ← תפריט ⋮ ← ״התקנת אפליקציה״ או ״הוספה למסך הבית״. לפעמים Chrome מציע התקנה בעצמו.
- **iPhone (Safari):** פתחו את הכתובת ב־Safari ← כפתור השיתוף ← ״הוספה למסך הבית״. ב־iPhone אין כפתור התקנה אוטומטי.

אפשרויות ההתקנה שונות בין דפדפנים ומערכות; דפדפנים אחרים עשויים לא להציע התקנה בכלל.

## מגבלות ידועות

- **iPhone במצב שקט (מתג הצד):** ייתכן שהצלילים לא יישמעו. זו מגבלה של המכשיר — המשחק ממשיך לעבוד עם משוב חזותי מלא.
- **ללא אינטרנט:** עובד רק אחרי פתיחה אחת מלאה עם אינטרנט. ניקוי נתוני האתר בדפדפן ידרוש טעינה מחדש עם אינטרנט.
- **תוצאות:** נשמרות רק בדפדפן שבמכשיר. ניקוי נתוני האתר, גלישה פרטית או דפדפן אחר — לא יציגו אותן.
- **עדכון גרסה:** גרסה חדשה נכנסת לתוקף בפתיחה הבאה של האפליקציה, לא באמצע משחק.

## פיתוח

```bash
npm install
npm run dev          # http://localhost:5173/simon/
npm test             # Vitest
npm run test:e2e     # Build + Playwright
npm run build && npm run preview   # http://localhost:4173/simon/ (כולל Service Worker)
npm run icons        # הפקת אייקוני PNG מתוך public/*.svg
```

כל Push לענף `main` מריץ בדיקות, בונה ומפרסם ל־GitHub Pages (`.github/workflows/deploy.yml`).
